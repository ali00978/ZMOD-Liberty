# G925 X v0.10: active experimental mobile Vulkan interpolation

G925 X defaults to the new portable compute provider; the launcher Display setting can explicitly turn it off. No NVIDIA/AMD desktop SDK or system driver changes. Mobile FSR 720p is recommended. Real game cap is preserved; host presentation targets up to 60 with two distinct immutable images. The provider only attempts 30/40 capped SDR frames of up to 900p/1.5M pixels, on FIFO, with consecutive scene submissions and 15–55ms intervals. The first frame seeds history. Gaps, duplicate scenes, surface epochs, unsupported format, allocation pressure and queue failures fall back to real frames. It uses final game color (HUD included); low confidence and disocclusion mismatches use current pixels. It is not FSR3 or AI, and game HUD artifacts are possible.

The implementation uses bounded frame pairs, graphics queue submission with mailbox timeline synchronization, fence-gated reuse and a shared lease through presentation. The actual APK contains the compute pipeline and dispatch; off-device shader validation does not establish phone FPS or visual quality. Native source changes require native compilation (cache reused where available). Test same scene with FG off/on, compare real FPS, displayed FPS, latency and heat. Disable FG if stutter or artifacts worsen. No claim of 60 real FPS.
