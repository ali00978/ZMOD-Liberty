# G925 X v0.11
Real title-update FPS remains measured by the existing hook. Output FPS counts unique successful Vulkan queue-present publications (real + generated), and FG FPS counts only generated publications. Queue acceptance is not physical panel scanout. UI-only repaints, duplicate real publications and failed presents are excluded.
The FG compute shader reduces motion-search texture reads per 16x16 tile from 450 (25 x 9 x 2) to 70 (13 x 5 + 5), before per-pixel reconstruction. This is a theoretical search-work reduction, not a measured FPS speedup; fewer search candidates can reduce motion quality. Skip new work when two GPU jobs are outstanding. Permit slow 60-cap runs to use FG with consecutive frame timing in 28–55ms range; fast real 60 FPS does not need interpolation. Keep existing fallback on resource/surface failures.
New opt-in FSR Mobile Performance preset renders at 640x360 for 1280x720 output; 43.7% fewer scene pixels than 853x480. No change to saved frame cap, draw distance, shadows or driver. Live dynamic resolution is deliberately not enabled: switching title render targets safely needs additional validation.
Host checks cover cadence and render extents, static integration, shader compilation, and the previous regression suite. Native APK compilation and real-phone FPS/latency/quality remain distinct checks.
