# Mali G925 v2.33 — lossless paired draw batching

Target: Dimensity 9500s / Mali G925, GTA IV ZMOD Liberty on Android.

The previous measured capture (v2.28) showed CPU native command recording about 23 ms and GPU frame about 20 ms, so a 16.67 ms / 60 FPS frame is not guaranteed by a build succeeding.

## Changes
- A nonadjacent pair of opaque, otherwise identical triangle-list indexed draws may now become one Vulkan draw when copying at most 384 guest indices. All index values, triangle ordering and vertex bases stay identical.
- The existing renderer requires identical shader/pipeline state, constants, descriptors, textures and vertex resources. Its stencil, blend, query and vertex-ID exclusions remain intact. Any allocation failure falls back to original rendering.
- The upper limit for consecutive exact DrawPrimitiveUp merges defaults to 32 (previously 16). No resolution, texture, shadow, shading or image quality settings are lowered.
- A compiled C++20 randomized two-draw byte-equivalence test runs on every APK CI build, and older 2.26/2.32 tests are updated to accept the expanded eligible set.

## Verification
The build and host CPU tests do not prove actual on-device FPS gain. To measure gains, use the same in-game scene with equal graphical settings on 2.32 vs 2.33, and compare GPU frame, CPU command recording, merged indexed draws, and title frame intervals.
